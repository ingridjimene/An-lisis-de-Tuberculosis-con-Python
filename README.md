# Análisis de Tuberculosis con Python
Análisis de datos sobre tuberculosis utilizando Python, Google Colab y librerías de visualización como Matplotlib, Seaborn y Plotly, con datos de la World Health Organization  

## Descripción del proyecto

Este proyecto fue desarrollado como parte de un proceso de aprendizaje en el uso de **Python para el análisis de datos**. El objetivo principal fue trabajar con información relacionada con la tuberculosis, utilizando datos obtenidos de la **World Health Organization (WHO)**, para practicar la manipulación de bases de datos, conexión con Google Drive y creación de visualizaciones.

A través de este análisis se aplicaron herramientas básicas y fundamentales de ciencia de datos, como la carga de información, asignación de valores, exploración de datos y generación de gráficas mediante librerías de visualización en Python.

## Objetivo

El objetivo de este proyecto es analizar datos relacionados con la tuberculosis utilizando Python, con el propósito de practicar habilidades esenciales en el manejo de datos y visualización de información.

De manera específica, este proyecto busca:

- Conectarse a Google Drive desde Google Colab.
- Cargar y manipular datos con Python.
- Asignar y transformar valores dentro del conjunto de datos.
- Explorar información relacionada con la tuberculosis.
- Crear visualizaciones para interpretar mejor los datos.
- Practicar el uso de librerías como Matplotlib, Seaborn y Plotly.

## Fuente de datos

Los datos utilizados en este proyecto fueron obtenidos de la:

**World Health Organization (WHO)**  
Organización Mundial de la Salud, organismo internacional encargado de recopilar y publicar información relacionada con temas de salud pública a nivel mundial.

Durante el desarrollo del proyecto se utilizaron diferentes librerías de Python para la manipulación y visualización de datos:

## Proceso realizado

### 1. Conexión con Google Drive

El proyecto inició con la conexión entre Google Colab y Google Drive, lo que permitió acceder a los archivos necesarios directamente desde la nube.

### 2. Carga de datos

Posteriormente, se cargó la base de datos relacionada con tuberculosis obtenida de la World Health Organization. Esta información fue utilizada como base para realizar el análisis.

### 3. Manipulación de datos

Se trabajó con los datos mediante Python, realizando acciones como:

- Lectura del archivo.
- Revisión de la estructura de la base de datos.
- Identificación de columnas relevantes.
- Asignación de valores.
- Organización de información.
- Preparación de los datos para su visualización.

### 4. Visualización de datos

Se realizaron diferentes tipos de gráficas para representar la información de forma más clara y comprensible. Para ello, se utilizaron librerías como:

- Matplotlib
- Seaborn
- Plotly

Estas visualizaciones ayudaron a observar patrones, comparar datos y comprender mejor el comportamiento de la tuberculosis dentro del conjunto de información analizado.
